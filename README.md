بوت شطرنج احترافي ومتكامل لمنصة **ديسكورد (Discord)** تم تطويره بواسطة المطور **Dark**، يولد صوراً ديناميكية عالية الدقة لرقعة الشطرنج بعد كل نقلة، ويدعم اللعب ضد **الذكاء الاصطناعي** بمستويات متعددة واللعب الثنائي ضد **الأصدقاء (PvP)** مع نظام تصنيف (ELO) ولوحة شرف للمتصدرين.

---

## ✨ المميزات الرئيسية

- 🖼️ **توليد صور عالية الدقة (HD Board Images):**
  - صورة عالية الجودة لرقعة الشطرنج بعد كل نقلة.
  - تظليل تلقائي لآخر نقلة تم لعبها باللون الأصفر الخفيف.
  - تظليل مربع الملك باللون الأحمر عند حدوث "كش ملك".
  - أسهم توضيحية خضراء تظهر عند طلب تلميح (Hint).
  - قلب الرقعة تلقائياً للاعب الأسود ليرى قطعه في الأسفل.

- 🤖 **محرك ذكاء اصطناعي مدمج وذكي (AI Engine):**
  - خوارزمية **Minimax** مع تقليم **Alpha-Beta** وبحث الهدوء (Quiescence Search).
  - جداول تقييم استراتيجي لمواقع القطع (Piece-Square Tables).
  - **4 مستويات صعوبة:**
    - 🟢 **سهل (Easy - 900 ELO):** للمبتدئين.
    - 🟡 **متوسط (Medium - 1400 ELO):** متوازن وممتع.
    - 🔴 **صعب (Hard - 1800 ELO):** تحدي تكتيكي قوي.
    - 🟣 **خبير (Master - 2100+ ELO):** لأقوى المنافسات.
  - دعم اختياري لمحرك **Stockfish** الخارجي إن أردت قوة جراند ماستر عالمية.

- ⚔️ **مباريات لاعب ضد لاعب (PvP):**
  - تحدي أي عضو في السيرفر مع أزرار قبول/رفض تفاعلية.
  - نظام تصنيف تنافسي عالمي **(ELO Rating)** يبدأ من 1200 نقطة.
  - إمكانية طلب التعادل، وقبول التعادل، والاستسلام.

- 🎮 **طرق لعب سهلة ومرنة للغاية:**
  - **كتابة النقلة مباشرة بالشات:** اكتب `e4` أو `e2e4` أو `Nf3` أو `O-O` وسيتعرف عليها البوت فوراً ويحذف الرسالة لتبقى القناة مرتبة!
  - **زر النقلة التفاعلي (♟️ إلعب نقلة):** يفتح نافذة منبثقة (Modal) لكتابة النقلة.
  - **أمر السلاش:** `/chess move notation:e4`.
  - **ترقية البيدق التلقائية:** تظهر أزرار فورية لاختيار (ملكة، رخ، فيل، حصان).

- 🎨 **5 ثيمات ألوان فخمة للرقعة:**
  - 🟢 **الزمرد الأخضر (Emerald):** مثل ستايل Chess.com الشهير.
  - 🪵 **الخشبي الفاخر (Wood):** تصميم كلاسيكي دافئ.
  - 🌊 **الأزرق المحيطي (Ocean Blue):** مريح للعين.
  - 🏆 **البطولات الكلاسيكي (Tournament):** أزرق وأبيض احترافي.
  - 🌙 **الليلي الداكن (Midnight Dark):** دارك مود أنيق.

- 📊 **إحصائيات وقاعدة بيانات متكاملة (SQLite):**
  - حفظ سجلات كل المباريات.
  - استعراض إحصائيات اللاعبين عبر `/chess stats`.
  - لوحة شرف لأفضل 10 لاعبين عبر `/chess leaderboard`.
  - تصدير سجل المباراة بصيغة **PGN** الرسمية عبر `/chess pgn`.

## 🚀 طريقة التثبيت والتشغيل خطوة بخطوة

### 1. المتطلبات:
- تثبيت بايثون (Python 3.10 أو أحدث - مثبت لديك بالفعل).

### 2. تثبيت المكتبات المطلوبة:
المكتبات مثبتة لديك ومجهزة بالكامل، ولكن إذا أردت التأكد:
```bash
pip install -r requirements.txt
```

---

### 3. إنشاء بوت في Discord Developer Portal:
1. اذهب إلى موقع مطوري ديسكورد: [Discord Developer Portal](https://discord.com/developers/applications).
2. اضغط على **New Application** واكتب اسماً للبوت (مثلاً `Chess Master` أو `شطرنج`).
3. من القائمة الجانبية، ادخل على تبويب **Bot**:
   - اضغط **Reset Token** لنسخ توكن البوت الخاص بك.
   - انزل لأسفل إلى قسم **Privileged Gateway Intents** وفعل الخيارين التاليين (مهم جداً):
     - ✅ **PRESENCE INTENT**
     - ✅ **SERVER MEMBERS INTENT**
     - ✅ **MESSAGE CONTENT INTENT** (لقراءة النقلات المكتوبة في الشات)
   - اضغط **Save Changes**.

4. دعوة البوت لسيرفرك:
   - من القائمة الجانبية ادخل على **OAuth2** ثم **URL Generator**.
   - في خانة **SCOPES** ضع علامة صح على:
     - `bot`
     - `applications.commands`
   - في خانة **BOT PERMISSIONS** اختر:
     - `Send Messages`
     - `Embed Links`
     - `Attach Files`
     - `Read Message History`
     - `Manage Messages` (اختياري، لحذف رسائل النقلات وإبقاء الروم نظيفة)
   - انسخ الرابط الذي يظهر بالأسفل وافتحه في المتصفح لإضافة البوت إلى سيرفرك.

---

### 4. وضع التوكن وتشغيل البوت:
1. افتح ملف `.env` في هذا المجلد:
```env
DISCORD_BOT_TOKEN=ضع_التوكن_الذي_نسخته_هنا
```
2. شغّل البوت بالأمر التالي:
```bash
python bot.py
```
ستظهر لك رسالة تأكيد في الشاشة:
```
✅ تم بنجاح مزامنة أوامر السلاش على ديسكورد.
♟️ بوت الشطرنج المتكامل يعمل الآن بنجاح!
```

## 🕹️ قائمة الأوامر التفاعلية (Slash Commands)

| الأمر | الوصف |
| :--- | :--- |
| `/chess ai` | بدء مباراة ضد الذكاء الاصطناعي (تحديد المستوى واللون والثيم) |
| `/chess challenge @user` | إرسال دعوة تحدي شطرنج لعضو في السيرفر |
| `/chess move <notation>` | تنفيذ نقلة في المباراة (مثال: `/chess move e4`) |
| `/chess board` | إعادة إظهار صورة الرقعة الحالية في القناة |
| `/chess hint` | الحصول على تلميح ذكي للنقلة القادمة |
| `/chess legal` | عرض قائمة النقلات المتاحة لك قانونياً في هذا الموقف |
| `/chess resign` | الاستسلام وإنهاء المباراة الحالية |
| `/chess pgn` | عرض وتصدير سجل المباراة بصيغة PGN |
| `/chess stats [@user]` | عرض إحصائياتك ونقاطك وتصنيفك في السيرفر |
| `/chess leaderboard` | عرض ترتيب أفضل 10 لاعبين في السيرفر |
| `/chess fen <fen>` | عرض صورة أي موقف شطرنج عبر كود FEN |
| `/chess help` | فتح دليل المساعدة والشرح المفصل |

## 💡 نصائح لكتابة النقلات:
- **تحريك البيدق:** اكتب المربع المستهدف فقط (مثال: `e4` أو `d5`).
- **تحريك القطع:** اكتب حرف القطعة الكبير ثم المربع (مثال: `Nf3` للحصان، `Bc4` للفيل، `Qh5` للوزير، `Ra1` للقلعة).
- **التبييت (Castling):** اكتب `O-O` للتبييت القصير أو `O-O-O` للتبييت الطويل (أو بصيغة UCI: `e1g1` أو `e8g8`).
- **صيغة UCI:** يمكنك أيضاً كتابة مربع البداية والنهاية مثل `e2e4` أو `g1f3`.
- البوت يدعم الأحرف الكبيرة والصغيرة دون أي مشاكل!
